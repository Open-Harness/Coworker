# Real things

| File | Is | Taken out |
|---|---|---|
| `pulls.json` | What happened on 35 pull requests of a public repo on GitHub, in order, with what GitHub says they are in the end. Read on 25 November 2026 from GitHub's public API | Names, titles, words |
| `mail/*.eml` | Bounces, delays, complaints and away notices that mail servers really sent, from [sisimai/set-of-emails](https://github.com/sisimai/set-of-emails), which made the names up already. BSD 2-Clause, © azumakuniyuki; the licence is beside them | – |
| `list.json` | The headers of one month of a public mailing list, as a conversation: ids, what answers what, when, who | Addresses, names, subjects, words |

GitHub's own published deliveries are in the package `@octokit/webhooks-examples`.
